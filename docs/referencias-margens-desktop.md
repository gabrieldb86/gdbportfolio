# Margens desktop — referências visuais

As referências Gloria Lo e Iuri Code apresentam conteúdos posicionados dentro de uma coluna editorial contida: em vez de expandir títulos, textos e cards até as bordas, preservam uma área lateral de respiro consistente. A referência de Gloria Lo evidencia uma grade central ampla e equilibrada; a de Iuri Code preserva um hero com largura útil menor que a viewport e um alinhamento contínuo entre marca, título, descrição e CTA.

## Aplicação no portfólio

A barra lateral fixa de 54px e seu avatar permanecem fora da alteração. Somente os contêineres internos da Home recebem uma largura máxima e margens automáticas em telas a partir de 901px. O mobile mantém suas regras de 24px e não recebe nenhum novo override.
