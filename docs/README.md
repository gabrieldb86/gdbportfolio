# Documentação do projeto

Esta pasta reúne a documentação atual do portfólio. Os arquivos foram organizados para separar instruções de uso diário, arquitetura e registros históricos.

| Documento | Finalidade |
|---|---|
| [`AI_HANDOFF.md`](AI_HANDOFF.md) | Contexto e regras para uma nova IA, desenvolvedor ou agência. |
| [`architecture/OVERVIEW.md`](architecture/OVERVIEW.md) | Arquitetura, rotas, SSR, dados e fluxo técnico. |
| [`guides/CONTENT_AND_VISUAL_EDITS.md`](guides/CONTENT_AND_VISUAL_EDITS.md) | Onde editar textos, imagens, SEO, estilos e versões mobile. |
| [`guides/OPERATIONS_AND_GITHUB.md`](guides/OPERATIONS_AND_GITHUB.md) | Instalação, comandos, validação, GitHub e publicação. |
| [`analytics-setup.md`](analytics-setup.md) | Referência histórica sobre a ativação de analytics. |
| [`history/README.md`](history/README.md) | Contexto dos relatórios e validações anteriores. |
| [`history/reports/`](history/reports/) | Arquivo organizado de diagnósticos e validações de rodadas passadas. |

Os documentos em `history/` são referência de decisões e validações passadas. Para mudanças novas, comece sempre pelos guias acima e pelo `todo.md` na raiz do repositório.
