# Histórico de relatórios e validações

Esta pasta reúne relatórios, diagnósticos, referências visuais e validações de rodadas anteriores. Os arquivos foram agrupados em [`reports/`](reports/) para manter a raiz do repositório focada em código e documentação atual. Eles são úteis para entender decisões passadas, mas não substituem a documentação ativa em `docs/`.

Use os arquivos históricos apenas quando for necessário recuperar o contexto de uma decisão específica. Para alterações novas, siga `docs/AI_HANDOFF.md`, atualize `todo.md` e valide o projeto pelos comandos documentados.
