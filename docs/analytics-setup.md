# Analytics do portfólio

O site já possui o script de mensuração leve configurado pelo ambiente e agora emite eventos de conversão para contatos, projetos e Behance. Para habilitar relatórios completos de aquisição no **Google Analytics 4**, informe `VITE_GA_MEASUREMENT_ID` no formato `G-XXXXXXXXXX`; o script é carregado somente após consentimento explícito do visitante.

## Leitura recomendada

| Fonte | Responde por |
| --- | --- |
| Google Analytics 4 | Usuários, sessões, canais de aquisição e eventos de contato. |
| Google Search Console | Consultas orgânicas, impressões, cliques, CTR e posição média. |
| PageSpeed Insights / Search Console | Core Web Vitals e experiência mobile. |

## Ativação do Search Console

1. Criar ou selecionar uma propriedade de domínio para `gabrielpor-7t6ygmlv.manus.space` no [Google Search Console](https://search.google.com/search-console/).
2. Concluir a verificação de propriedade pelo método oferecido pelo Google.
3. Enviar o sitemap quando existir uma versão definitiva do domínio.
4. Vincular a propriedade Search Console à propriedade GA4 para comparar consultas orgânicas e sessões.

Não é possível obter consultas efetivamente pesquisadas, posições ou impressões apenas pelo código do site: esses dados dependem da propriedade verificada no Search Console e de histórico de coleta.
