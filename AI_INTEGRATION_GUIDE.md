# Guia de entrada para IAs e ferramentas externas

Este arquivo existe para que outra IA, desenvolvedor ou agência comece pelo contexto correto sem depender de histórico de conversa.

1. Leia [`README.md`](README.md).
2. Leia [`docs/AI_HANDOFF.md`](docs/AI_HANDOFF.md) antes de editar qualquer arquivo.
3. Consulte [`docs/architecture/OVERVIEW.md`](docs/architecture/OVERVIEW.md) para localizar rotas, dados, SSR e SEO.
4. Use [`docs/guides/CONTENT_AND_VISUAL_EDITS.md`](docs/guides/CONTENT_AND_VISUAL_EDITS.md) para alterações de conteúdo e interface.
5. Siga [`docs/guides/OPERATIONS_AND_GITHUB.md`](docs/guides/OPERATIONS_AND_GITHUB.md) para executar, validar e sincronizar mudanças.

> Valores atuais de referência: **17+ anos de experiência**, **114K+ pessoas capacitadas** e **130+ promotores monitorados**. Não restaurar métricas antigas de 300K.

O projeto é uma aplicação React/TypeScript com SSR. O conteúdo visual não deve ser redesenhado sem pedido explícito, e nenhuma alteração deve expor o telefone como texto público.
